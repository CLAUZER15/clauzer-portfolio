A responsive one-page portfolio for fantasy and D&D commissions.

- Vanir — Character Study (front/profile sketches + painted views)

## Character lore
The site includes expandable lore cards for Vanir and Eldric Vane. Short introductions stay visible, while the longer backstories remain collapsed behind “Read story” controls so the portfolio does not feel text-heavy.
