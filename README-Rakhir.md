# CLAUZER — Rakhir update

This package adds Rakhir — The Wandering Claw to the existing CLAUZER portfolio.

## Upload to GitHub Pages
1. Replace your current `index.html` with the `index.html` in this package.
2. Upload `rakhir.webp` to the same repository root as `index.html`.
3. Keep your existing Vanir/Eldric artwork files unchanged.
4. Commit the changes and wait for GitHub Pages to redeploy.

Rakhir appears in both the Portfolio gallery and the Character Lore section.
